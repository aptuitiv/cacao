---
title: Print width - thirds
---

This provides styles for widths using thirds that only apply when the page is printed.

The following sizes are available:

- print-w-1-3
- print-w-2-3
- print-w-3-3

Each width size has a class to go with each of the [media query viewport sizes](/styles/media#viewport-media-queries). For example:

```css
print-w-1-3-3xs
print-w-1-3-2xs
print-w-1-3-xs
print-w-1-3-sm
print-w-1-3-md
print-w-1-3-lg
print-w-1-3-xl
print-w-1-3-2xl
print-w-1-3-3xl
print-w-1-3-4xl
print-w-1-3-5xl
```

## How to import into your CSS

Import this into your CSS with:

```css
@import 'cacao-css/dist/width/print-width-3.css';
```

Imports are available for all [media query viewport sizes](/styles/media#viewport-media-queries).

```css
@import 'cacao-css/dist/width/3xs/print-width-3.css';
@import 'cacao-css/dist/width/2xs/print-width-3.css';
@import 'cacao-css/dist/width/xs/print-width-3.css';
@import 'cacao-css/dist/width/sm/print-width-3.css';
@import 'cacao-css/dist/width/md/print-width-3.css';
@import 'cacao-css/dist/width/lg/print-width-3.css';
@import 'cacao-css/dist/width/xl/print-width-3.css';
@import 'cacao-css/dist/width/2xl/print-width-3.css';
@import 'cacao-css/dist/width/3xl/print-width-3.css';
@import 'cacao-css/dist/width/4xl/print-width-3.css';
@import 'cacao-css/dist/width/5xl/print-width-3.css';
```

See [Import Cacao CSS](/import) for more information.
