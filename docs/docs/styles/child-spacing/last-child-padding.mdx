---
title: Last child padding styles
---

The last child padding styles allow you to modify the padding for the last child in an element.

## Available padding styles

- All sides padding
- Bottom padding
- End padding
- Horizontal padding
- Start padding
- Top padding
- Vertical padding

## Combined import

You can import all of the last child padding styles with the following import:

```css
@import 'cacao-css/dist/child-spacing/last-child/padding/combined-import.css';
```

## How to import into your CSS

Import this into your CSS with:

```css
@import 'cacao-css/dist/child-spacing/last-child/padding/all.css';
@import 'cacao-css/dist/child-spacing/last-child/padding/bottom.css';
@import 'cacao-css/dist/child-spacing/last-child/padding/end.css';
@import 'cacao-css/dist/child-spacing/last-child/padding/horizontal.css';
@import 'cacao-css/dist/child-spacing/last-child/padding/start.css';
@import 'cacao-css/dist/child-spacing/last-child/padding/top.css';
@import 'cacao-css/dist/child-spacing/last-child/padding/vertical.css';
```
