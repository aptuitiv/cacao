---
title: Last child spacing styles
---

The last child spacing styles allow you to modify the spacing (i.e. margin and padding) for the last child in an element.

## Available spacing styles

- All sides spacing
- Bottom spacing
- End spacing
- Horizontal spacing
- Start spacing
- Top spacing
- Vertical spacing

## Combined import

You can import all of the last child spacing styles with the following import:

```css
@import 'cacao-css/dist/child-spacing/last-child/spacing/combined-import.css';
```

## How to import into your CSS

Import this into your CSS with:

```css
@import 'cacao-css/dist/child-spacing/last-child/spacing/all.css';
@import 'cacao-css/dist/child-spacing/last-child/spacing/bottom.css';
@import 'cacao-css/dist/child-spacing/last-child/spacing/end.css';
@import 'cacao-css/dist/child-spacing/last-child/spacing/horizontal.css';
@import 'cacao-css/dist/child-spacing/last-child/spacing/start.css';
@import 'cacao-css/dist/child-spacing/last-child/spacing/top.css';
@import 'cacao-css/dist/child-spacing/last-child/spacing/vertical.css';
```
